One original one-line joke about office life, under 200 characters. `main.py` (Python 3.13, standard library only, no network) writes exactly that line to `entry.txt` and prints it — nothing else. Deterministic: every run produces the same bytes.

## The joke

> I hit reply-all to ask everyone to stop hitting reply-all, and now the whole company is hitting reply-all to agree with me.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the 123-character line to `out/entry.txt` and prints it. Without `MAKEFUN_OUTPUT_DIR` it writes to `/output/entry.txt`, as the grader expects.
